# Chapter 2 — The Ingredients (and the Gap)

The structure side of the pipeline:

- **VAT** — visual assessment of cluster tendency; works on a *dissimilarity matrix alone*, no coordinates
- **Minimax transform** — makes single-linkage hierarchy the right object for relational data
- **Persistence** — reads cluster scales off the hierarchy; the count $k$ can be an *output*, not an input

The gap this dissertation fills: every method above stops at a **crisp partition** — none answers *"to what degree does each point belong"*, and none builds a fuzzy inference system.
