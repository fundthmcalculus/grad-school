Final invertible fuzzy model

A 100,000-parameter character model in which the embedding is an exactly invertible fuzzy map that is also the de-embedding, every layer is a first-order fuzzy rule system, and the dictionary of characters is built by hand with every coordinate named. Trained on 300 million characters of Cosmopedia v2 (a 3-billion-character corpus; the run sees a tenth of it, no text repeated).

On Cosmopedia

Validation bits per character, mean of two seeds (dots are seeds). Lower is better. The tied head is the same model without the invertible layer, at its own 100K shape.

What freezing the named dictionary costs, by corpus

Same model, same size, three corpora at 300M characters. The cost of keeping the named dictionary fixed grows with how varied the text is. The weak pull-back lets the dictionary move a little and keeps it recognisable.

Doubling the size

The same model at 200,000 parameters (448 rules per system) on Cosmopedia at 300M characters. Doubling the parameters is the strongest lever; the cost of keeping the named dictionary fixed shrinks as the model grows. Seeds in brackets.

Across corpora

The models trained on Cosmopedia, tested on three corpora (2,000 windows of 256 characters each). They do not transfer well: the Pile-trained model of the same size scores 2.35 on the Pile and the TinyStories-trained one 1.24 on TinyStories.

Can it be explained?

Each block's rules, read out directly (Cosmopedia text). Silencing the eight most-used rules always costs more than the worst of ten random eight-rule draws, so the rulebook is causal. One rule's identity tells less about the next character than the previous character does in the first block (bits of mutual information, previous character: ).

Exactness

Text in, the same text out through the embedding and its inverse: 0 wrong symbols in float64 and float32, on short text, a pangram, 2,000 held-out symbols and every symbol shuffled twenty times (largest reconstruction error 1e-15 in float64, 5e-7 in float32). Characters outside the 98-symbol vocabulary become one unknown symbol and come back as it.

Greedy text, honestly

Greedy decoding loops on all of these models; the invertible ones loop more than the tied head. This is the known failure of a 100,000-parameter character model decoding greedily, not an explanation of anything.
